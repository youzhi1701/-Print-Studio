# 超级打印（飞书打印插件）

> 当前版本：**v20261006-21**

超级打印是一套面向 **飞书多维表格** 的模板编辑与打印工具，核心目标是把“选记录 → 选模板 → 编辑 → 预览 → 打印”做成一条稳定、直观、可复用的工作流。

项目重点不是营销展示，而是 **真正可用的打印编辑器和打印执行能力**。

---

## 核心能力

### 1. 飞书数据打印
- 读取飞书多维表格当前记录与选中记录
- 支持单条打印、批量打印
- 支持飞书字段自动识别与自动绑定
- 支持图片附件、文本、订单信息等数据进入模板

### 2. 模板编辑器
- 拖拽式画布编辑
- 网格、吸附、安全区、标尺
- 撤销 / 重做
- 位置与尺寸精确调整
- 图层管理
- 多选、对齐、层级调整
- 打印校准：横向偏移、纵向偏移、输出缩放

编辑器当前支持：
- 文本
- 数据字段
- 图片
- 明细表格
- 条码
- 二维码
- 分隔线
- 容器

### 3. 所见即所得
编辑器、实际预览和最终打印尽量共用同一套渲染逻辑，减少“编辑时一套、打印时另一套”的偏差。

当前重点包括：
- 字段真实数据显示
- 文本自动高度
- 表格行列与边框一致
- 图片适配一致
- 条码 / 二维码一致
- 预览与打印使用统一尺寸和位置


### 自动表格（v20261006-21）
- 新增表格会按当前纸张安全区自动确定宽度
- 小标签自动减少默认列数，避免机械塞入过多字段
- 商品名称、规格、数量、价格按内容重要性分配列宽
- 长文本自动估算所需行高，减少文字被裁切
- 空列默认自动隐藏
- 页面尺寸变化时，自动布局表格会重新适配
- 属性栏提供“一键自动适配页面”和超出页面提示
- 用户手动修改列宽或表格宽度后，会尊重人工布局，不反复强制重排

### 4. 模板库
模板库分为：
- **内置模板**
- **我的模板**

编辑器支持：
- 添加到我的模板库
- 保存修改
- 另存为
- 删除模板

内置模板不会被直接覆盖或删除，需要先复制到“我的模板”。

### 5. 私人模板库
支持通过手机号识别私人模板空间。

当前逻辑：
1. 输入手机号
2. 已存在用户：进入原私人模板库
3. 新手机号：自动注册用户
4. 自动创建私人模板空间
5. 模板按用户 ID 隔离
6. 云端同步后可跨设备继续使用

手机号仅作为身份入口，模板数据按用户账户隔离，不以本地浏览器数据作为唯一依据。

### 6. 打印预览
- 独立成品预览窗口
- 适配 / 还原 / 放大 / 缩小
- 拖动画布
- 多记录前后切换
- 打印当前 / 打印全部
- Ctrl + P 打印

## 环境变量

生产环境至少需要：

```text
SESSION_SECRET
KV_REST_API_URL
KV_REST_API_TOKEN
```

Upstash / Vercel 集成通常还会自动生成：

```text
KV_URL
KV_REST_API_READ_ONLY_TOKEN
REDIS_URL
```

### SESSION_SECRET

用于服务端 Session 签名。

建议：
- 至少 24 位
- 推荐 48～64 位随机字符串
- 不要提交到 GitHub
- Production 和 Preview 可分别配置

### Redis

后端当前兼容：

```text
KV_REST_API_URL
KV_REST_API_TOKEN
```

也兼容 Upstash 原生命名：

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
```

## 健康检查

部署后可访问：

```text
/api/health
```

正常情况下应返回：

```json
{
  "sessionConfigured": true,
  "storageConfigured": true,
  "storageReady": true
}
```

三个值均为 `true` 时，说明 Session 与 Redis 基础环境可用。

## 本地运行

### 推荐：Vercel CLI

因为项目包含 `/api` Serverless 接口，完整本地调试建议使用 Vercel CLI。

```bash
npm i -g vercel
vercel dev
```

如果只检查静态页面，也可以使用任意静态服务器打开项目，但账户登录、云模板等 API 功能需要 Serverless 环境。

## 模板数据原则

### 内置模板
- 系统提供
- 不允许直接删除
- 不直接覆盖
- 需要“添加到我的模板库”后编辑

### 我的模板
- 当前用户私有
- 支持编辑
- 支持保存修改
- 支持另存为
- 支持删除
- 登录后支持云端同步

### 用户隔离
不同手机号登录后：
- 本地模板空间分离
- 云端模板空间分离
- 删除标记分离
- 当前模板设置分离

## 打印设计原则

本项目当前遵循以下原则：

1. **编辑与打印优先**
2. **所见即所得**
3. **真实数据优先，不用假占位替代最终效果**
4. **尺寸使用 mm 作为打印逻辑基础**
5. **模板、预览、打印尽量共用同一渲染器**
6. **内置模板和私人模板严格分离**
7. **用户私人模板按账户隔离**
8. **打印文字和表格边框优先保证清晰度**

## 已知限制

- 浏览器打印仍受操作系统打印驱动、缩放和打印机硬件影响。
- 热敏打印机、普通喷墨/激光打印机在字体粗细和边框表现上存在差异。
- Vercel 免费计划存在部署/API 调用额度限制。
- 跨设备私人模板同步依赖 Vercel API 和 Upstash Redis 正常可用。
- 条码、二维码渲染依赖前端运行环境和相关模块加载成功。
- 飞书字段类型较多，特殊字段仍可能需要继续适配。
