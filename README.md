## 项目概览

超级打印不是营销展示页，而是一套真正用于编辑与打印的业务工具。项目围绕“快速打印”和“模板设计器”两条主线展开，并通过统一渲染逻辑尽量保证编辑、预览和最终打印结果一致。

当前生产部署：

- Vercel Project：`super-print`
- Production Domain：`feishu-print-ashen.vercel.app`
- 数据来源：飞书多维表格 SDK
- 私人模板存储：Upstash Redis

---

## 核心能力

### 快速打印
- 读取飞书多维表格当前记录与选中记录
- 支持单条打印与批量打印
- 自动识别常见飞书字段
- 支持文本、图片、订单信息等数据进入模板
- 首页保留必要操作入口，重点展示成品预览

### 模板设计器
- 拖拽式画布
- 网格、吸附、安全区与标尺
- 撤销 / 重做
- 多选、对齐、层级调整
- 精确位置与尺寸
- 文本、数据字段、图片、明细表格、条码、二维码、分隔线和容器
- 打印校准：横向偏移、纵向偏移、输出缩放

### v20261008-38 数据字段实时更新修复
- 修复“右侧显示内容已经修改，但画布不变化”的问题
- 根因是新增加的 `fieldTemplate` 输入框未注册到设计器统一 `input/change` 更新链路
- 现在输入时立即刷新画布，失焦/修改完成后进入历史记录与自动保存
- 去除已废弃的 `fieldLabel` 更新触发残留

### 数据字段
- “数据字段”组件只保留一个 **显示内容** 模板，不再拆成“表头 + 内容”两套输入
- 绑定“电话”时默认生成 `电话：{{电话}}`
- 模板可任意修改，例如 `{{电话}}`、`联系电话：{{电话}}`、`{{姓名}} / {{电话}}`
- 更换绑定字段时，仅当显示内容仍是默认模板才自动跟随，不覆盖用户自定义内容
- 兼容旧模板的 label + text 数据，但用户一旦编辑即统一写入单一模板
- 编辑画布、成品预览和打印统一解析同一份显示内容模板

### v20261008-38 表格属性面板
- 列配置改为分层卡片，不再把拖动、表头、字段、内容模板、删除全部挤在一行
- 每列按“表头 / 字段 / 内容”清晰分区
- 内容模板使用整行多行输入框，可完整输入 `{{商品名称}}`、`商品：{{商品名称}}` 等长内容
- 保留列拖动排序、删除、字段自动跟随和画布实时刷新

### v20261008-38 紧凑列配置
- 表格列配置改为折叠列表，默认只显示“列名 + 绑定字段”，不再同时展开所有列的表头/字段/内容
- 点击某一列才展开编辑完整内容，同一时间只展开一列
- 保留拖动排序、字段绑定、自由内容模板与删除
- “选中单元格”高级编辑默认收起，只有选中单元格后主动点击“高级单元格”才展开
- 右侧属性栏优先展示常用功能，减少纵向滚动与重复标签

### v20261008-38 表格列配置精简
- 删除列配置里的“内容”编辑板块，表格正文直接跟随绑定字段
- 每列保留“表头 / 字段 / 表头对齐”三个核心设置
- 表头支持左 / 中 / 右独立对齐，不再强制跟随正文单元格对齐
- 保留列拖动排序、删除、列宽拖动和高级单元格编辑

### 自动表格
- 每列支持“表头 + 绑定字段 + 自由内容模板”
- 表头默认跟随绑定字段标题，但用户手动修改后保持自定义内容
- 内容模板默认生成 `{{字段名}}`，可与固定文字或多个字段自由混排，例如 `电话：{{电话}}`、`{{收件人}} / {{电话}}`
- 更换或自动匹配绑定字段时，仅当表头/内容仍处于默认状态才自动跟随，不覆盖用户自定义内容
- 兼容旧模板：旧列没有内容模板时自动补为 `{{绑定字段}}`，避免“界面可填但画布不生效”
- 按纸张安全区自动确定初始宽度
- 小标签自动减少默认列数
- 按内容重要性分配列宽
- 长文本自动估算行高
- 空列默认隐藏
- 页面尺寸变化时重新适配
- 用户手动修改后尊重人工布局，不反复强制重排

### 模板库
模板分为：
- **内置模板**
- **我的模板**

支持添加、保存修改、另存为与删除。内置模板不会被直接覆盖或删除，需要先复制到“我的模板”。

### 私人模板空间
支持通过手机号进入私人模板空间：
1. 输入手机号
2. 已存在用户进入原模板库
3. 新手机号自动创建用户与私人空间
4. 模板按用户 ID 隔离
5. 云端同步后可跨设备继续使用

### 成品预览
- 独立成品预览
- 适配 / 还原 / 放大 / 缩小
- 拖动画布
- 多记录切换
- 打印当前 / 打印全部
- Ctrl + P 打印

## 构建与发布

项目以静态前端 + Vercel Serverless API 方式部署。

生产环境至少需要：

```text
SESSION_SECRET
KV_REST_API_URL
KV_REST_API_TOKEN
```

同时兼容 Upstash 原生命名：

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
```

`SESSION_SECRET` 仅用于服务端会话签名，不应提交到仓库。

正式版本统一在 GitHub Releases 中保留版本快照，生产站点继续由 Vercel 承担在线部署。

## 数据、安全与使用边界

- 飞书业务数据仅用于当前打印与模板渲染流程
- 私人模板按用户空间隔离
- Session 密钥与 Redis Token 不提交到 GitHub
- 手机号当前作为私人模板空间的身份入口，不等同于高安全等级身份认证
- 打印结果仍应在正式输出前通过成品预览复核
